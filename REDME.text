PROJECT OVERVIEW
Nos Vemos Travel Atelier is a premium Spanish-language travel atelier website.
The brand direction is:
- Elegant
- Editorial
- Cinematic
- Luxurious but warm
- Sophisticated without looking corporate
- High-end yet human
- Minimal but visually rich

The website should feel like a boutique luxury travel magazine combined with a modern premium concierge service.

TECH STACK

- Vite
- TypeScript
- Tailwind CSS
- React Router
- lucide-react icons
- framer-motion animations
